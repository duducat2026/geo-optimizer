快速开始（3 分钟上手）

无需编程基础，四条命令完成 AI 搜索优化全流程。

# 安装（Python 3.10+）
git clone https://github.com/duducat2026/geo-optimizer.git
cd geo-optimizer && pip install -e ".[dev]"
playwright install chromium

# 第1步：诊断 GEO 就绪度（获取 11 引擎评分报告）
geo-optimizer analyze https://your-site.com

# 第2步：LLM 生成优化内容（FAQ/Schema/多平台内容）
geo-optimizer optimize https://your-site.com

# 第3步：导出到各大平台（微信/知乎/头条/Medium/Quora/Reddit）
geo-optimizer export https://your-site.com

# 第4步：持续监控 AI 引擎排名
geo-optimizer monitor https://your-site.com

# 启动 Web 管理平台（多用户/配额/审计）
geo-web --port 5000

常见问题

关于 GEO 优化和 GEO-Optimizer 的高频问题解答。

GEO-Optimizer 和传统 SEO 工具有什么区别？

传统 SEO 工具（如 Ahrefs、SEMrush）关注搜索引擎结果页排名，优化手段以关键词、外链、技术SEO为主。GEO-Optimizer 专注于 AI 搜索引擎的引用优化——结构化数据（Schema JSON-LD）、E-E-A-T 权威信号、对话式 FAQ、AI 爬虫兼容性。简单来说：SEO 让你被搜到，GEO 让你被 AI 引用。两者互补，不冲突。

什么是 GEO（生成式引擎优化）？为什么 2026 年必须做？

GEO（Generative Engine Optimization）是针对 AI 搜索引擎的内容优化策略。当用户向豆包、ChatGPT、Perplexity 提问时，AI 会从互联网内容中选择权威来源进行引用。2025 年全球 AI 搜索用户已超 5 亿，且增速远超传统搜索。不做 GEO，意味着你的内容在 AI 回答中完全缺席，等同于在新时代「隐身」。

网站流量下降了，是不是跟 AI 搜索有关？

很可能是。大量用户从传统搜索转向 AI 问答，如果 AI 引擎不引用你的内容，流量会持续流失。解决方案：用 GEO-Optimizer 诊断评分，重点优化结构化数据、添加 FAQ 内容、确保 robots.txt 允许 AI 爬虫（GPTBot/ClaudeBot/PerplexityBot/Bytespider），并在高权重平台发布引用你网站的内容。

怎么让豆包 / ChatGPT 推荐我的网站？

关键四步：(1) 在对应生态发布内容——豆包偏好头条/抖音生态，ChatGPT 依赖 Bing 索引；(2) 添加 Schema 结构化数据让 AI 能解析你的内容；(3) 建立 E-E-A-T 权威信号（作者信息、引用来源、发布日期）；(4) 确保 robots.txt 允许对应爬虫。GEO-Optimizer 可一键诊断并自动生成全部优化内容。

GEO 优化需要多长时间见效？

通常 2-4 周可观察到变化。结构化数据优化（Schema/FAQ）生效最快（1-2 周），平台内容分发需要各平台索引周期（2-4 周），E-E-A-T 权威建立是长期过程（1-3 个月）。建议用 monitor 功能每周跟踪排名变化。

是否免费？需要什么环境？

免费开源（AGPL-3.0），个人与开源项目可自由使用与分发；闭源商用/SaaS 需遵守 AGPL 条款或获取商业授权。Python 3.10+ 环境即可运行。LLM 内容生成需配置阿里云百炼 API Key（有免费额度），也支持 Token Plan 团队版或任何 OpenAI 兼容接口。

What is GEO and how to optimize for AI search engines?

GEO (Generative Engine Optimization) is the practice of optimizing web content to be cited by AI-powered search engines. Key strategies: add structured data (Schema.org JSON-LD), build E-E-A-T authority signals, create conversational Q&A content, allow AI crawlers in robots.txt, and publish on authoritative platforms. GEO-Optimizer automates this entire workflow across 11 AI engines.
