GEO-Optimizer

A Generative Engine Optimization (GEO) toolchain for AI search engines — get your site cited by ChatGPT, Perplexity, Google AI Overviews, Doubao and more

In one sentence: GEO-Optimizer is a free, open-source AI search optimization tool that walks you through four steps — diagnose and score, generate content with an LLM, distribute across platforms, monitor ranks — keeping your site visible in the AI search era. It covers five Chinese plus six global AI engines, runs on Python 3.10+, and is licensed under AGPL-3.0.

Core capabilities

From diagnosis to optimization to distribution to monitoring, GEO-Optimizer covers the whole AI search optimization chain.

🔍 Evaluation across 11 engines

Doubao, Tongyi Qianwen, Hunyuan, ChatGLM, DeepSeek + Google AI Overviews, ChatGPT Search, Perplexity, Claude, Copilot, Gemini — each engine scored and advised independently

📊 Dual-engine scoring model

Five Chinese dimensions (content quality / structured data / citation readiness / AI crawler compatibility / user experience) plus six global ones (E-E-A-T / structured / citation / coverage / depth / readability)

🤖 LLM-powered content generation

Calls qwen-plus/qwen-max to generate FAQ pairs, Schema JSON-LD structured data and platform-adapted drafts automatically — nothing to write by hand

📤 One-shot export to six platforms

WeChat, Zhihu, Toutiao, Medium, Quora, Reddit — formatting and length limits adapted per platform

📈 Continuous rank monitoring

Scheduled checks of how target keywords are cited in each AI engine, with change notifications and trend analysis

👥 Multi-user web platform

Admin/user roles, evaluation quotas, audit trail, live task monitoring, PDF report export, ZIP bundle download

🔌 Open API & MCP server

RESTful API with Bearer Token auth (submit / status / results / usage) plus a streamable-HTTP MCP server with 8 tools and a ClawHub Agent SKILL package

🕷️ Index and crawler checks

One command checks your site's index status (HTTPS / robots.txt / sitemap) and its AI crawler compatibility (GPTBot / ClaudeBot / PerplexityBot)

Quick start (3 minutes)

No programming background needed — four commands cover the whole AI search optimization flow.

# Install (Python 3.10+)
git clone https://github.com/duducat2026/geo-optimizer.git
cd geo-optimizer && pip install -e ".[dev]"
playwright install chromium

# Step 1: diagnose GEO readiness (score report for 11 engines)
geo-optimizer analyze https://your-site.com

# Step 2: generate optimized content with an LLM (FAQ / Schema / platform drafts)
geo-optimizer optimize https://your-site.com

# Step 3: export for every platform (WeChat / Zhihu / Toutiao / Medium / Quora / Reddit)
geo-optimizer export https://your-site.com

# Step 4: keep monitoring AI engine citation ranks
geo-optimizer monitor https://your-site.com

# Start the web management platform (multi-user / quotas / audit)
geo-web --port 5000

Frequently asked questions

Answers to the most common questions about GEO and about GEO-Optimizer itself.

How is this different from Ahrefs or Semrush?

Traditional SEO tools track SERP rankings and optimize through keywords, backlinks and technical fixes. GEO-Optimizer focuses on being cited by AI search engines — structured data (Schema JSON-LD), E-E-A-T authority signals, conversational FAQs and AI-crawler compatibility. In short: SEO gets you found, GEO gets you quoted. The two work together, not against each other.

What is Generative Engine Optimization and why does it matter in 2026?

GEO is the practice of optimizing content so AI search engines cite it. When users ask ChatGPT, Perplexity or Doubao, the model selects authoritative sources from the web to reference. Global AI search users passed 500 million in 2025 and grow far faster than classic search. Without GEO your content is simply absent from AI answers — invisible in the new era.

My traffic dropped — is AI search to blame?

Very likely. Users shifted from classic search to AI answers, and traffic keeps draining if no engine cites you. Diagnose your score with GEO-Optimizer, then prioritize structured data, add FAQ content, confirm robots.txt allows AI crawlers (GPTBot / ClaudeBot / PerplexityBot / Bytespider), and publish supporting content on high-authority platforms that reference your site.

How do I get Doubao or ChatGPT to recommend my site?

Four decisive steps: (1) publish inside the right ecosystem — Doubao favours the Toutiao/Douyin ecosystem while ChatGPT Search leans on the Bing index; (2) add Schema structured data so models can parse your content; (3) build E-E-A-T signals with author info, cited sources and publication dates; (4) make sure robots.txt allows the relevant crawler. GEO-Optimizer diagnoses all of it and generates the fixes.

How long before GEO changes take effect?

You usually see citation shifts within 2-4 weeks. Structured data work (Schema/FAQ) is fastest (1-2 weeks), platform distribution follows each platform's indexing cycle (2-4 weeks), and E-E-A-T authority is a 1-3 month effort. Use the monitor command to review rank movement weekly.

Is it free? What do I need to run it?

Free and open source under AGPL-3.0 — personal and open-source projects may use and redistribute it freely; closed-source commercial or SaaS use must comply with AGPL or obtain a commercial license. Python 3.10+ is enough to run it. LLM generation needs an Alibaba Cloud Bailian API key (a free tier exists), a Token Plan team key, or any OpenAI-compatible endpoint.

Can I self-host or embed it in my own agent stack?

Yes. docker compose up -d starts the web platform plus MySQL, and --profile mcp adds the MCP server. Agents can call the eight streamable-HTTP MCP tools or install the ClawHub SKILL package from docs/geo-skill/. Source: github.com/duducat2026/geo-optimizer.
